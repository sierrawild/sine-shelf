# Sine Shelf

A shelf of sine and cosine motions. Pick a preset, change the formula, and watch the shape move. Copy the result into Python or JavaScript.

https://sierrawild.github.io/sine-shelf/

`t` is time in seconds. `s` runs from 0 to 1 along a curve. If a formula uses `s`, the preview draws the whole curve. Otherwise it draws one moving point and its trail.

The grid is −1 to 1. Multiply the copied formula by your pixel scale. Motions you save stay in this browser.

## Similar sites

- [Desmos](https://www.desmos.com/calculator) is a graphing calculator. A row can be switched to parametric.
- [Graphtoy](https://graphtoy.com) plots formulas you type.
- [easings.net](https://easings.net) is a shelf of motion curves with code to copy. The formulas are fixed.
- [cubic-bezier.com](https://cubic-bezier.com) is for one cubic Bézier ease, the kind CSS uses.
- [GeoGebra](https://www.geogebra.org/graphing) is a fuller graphing tool, including parametric curves.
